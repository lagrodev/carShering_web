# Обновление приложения: LocalDateTime и статистика пользователя

## Обзор изменений

В соответствии с обновлённым API были внесены следующие изменения в frontend приложение:

### 1. Переход на LocalDateTime (вместо LocalDate)

#### Затронутые компоненты:

**a) Фильтры поиска автомобилей (`HomeView.vue`)**
- Изменены поля `dateStart` и `dateEnd` с `type="date"` на `type="datetime-local"`
- Обновлены минимальные значения с `.split('T')[0]` на `.slice(0, 16)` для поддержки времени
- Фильтры теперь отправляют полные datetime значения в формате ISO 8601

**b) Форма создания контракта (`CreateContractView.vue`)**
- Поля ввода дат изменены на `datetime-local`
- Обновлена функция парсинга: `parseDate()` → `parseDateTime()`
- Валидация теперь учитывает часы и минуты
- Расчёт стоимости основан на часах аренды (цена указана за час)
- Добавлено отображение длительности в часах и днях
- Лейблы обновлены: "Дата начала" → "Дата и время начала аренды"

**c) Сервис контрактов (`contractService.js`)**
- Добавлены комментарии о формате ISO 8601 для LocalDateTime
- Данные отправляются в формате, который браузер генерирует для `datetime-local`

### 2. Новый эндпоинт статистики пользователя

#### Добавленные файлы:

**a) `services/analyticsService.js`**
- Новый сервис для работы с эндпоинтом `/overview/client`
- Функция `getUserStats()` получает статистику пользователя

**b) `components/profile/UserStatsCard.vue`**
- Компонент для отображения статистики пользователя
- Показывает:
  - Любимый автомобиль с изображением
  - Общее количество поездок
  - Поездки за текущий месяц
  - Общую сумму затрат
  - Любимый бренд и класс авто
  - Среднюю длительность поездки
  - Среднее время начала поездок
  - Среднюю стоимость за час
  - Дату последней поездки
- Включает состояния загрузки, ошибки и пустого состояния

**c) Интеграция в профиль (`ProfileView.vue`)**
- Импортирован компонент `UserStatsCard`
- Добавлен в конец страницы профиля после кнопки выхода

### 3. Изменения в обработке дат

#### До:
```javascript
// Только дата
const todayStr = today.toISOString().split('T')[0] // "2025-11-25"
type="date"
```

#### После:
```javascript
// Дата и время
const todayStr = today.toISOString().slice(0, 16) // "2025-11-25T14:30"
type="datetime-local"
```

### 4. Расчёт стоимости аренды

#### До (по дням):
```javascript
const rentalDuration = computed(() => {
  // Возвращал количество дней
  return Math.ceil((end - start) / (1000 * 60 * 60 * 24))
})

// Цена умножалась на дни
totalCost = rent * rentalDuration
```

#### После (по часам):
```javascript
const rentalDuration = computed(() => {
  // Возвращает количество часов
  return Math.ceil((end - start) / (1000 * 60 * 60))
})

const rentalDurationDays = computed(() => {
  // Для отображения
  return Math.ceil((end - start) / (1000 * 60 * 60 * 24))
})

// Цена умножается на часы
totalCost = rent * rentalDuration
```

### 5. API соответствие

Приложение теперь полностью соответствует обновлённой документации API:

- ✅ Фильтры `date_start` и `date_end` отправляются как `LocalDateTime`
- ✅ Контракты создаются с `dataStart` и `dataEnd` в формате `LocalDateTime`
- ✅ Эндпоинт `/overview/client` для статистики интегрирован
- ✅ Все поля ответа `UserStats` корректно обрабатываются

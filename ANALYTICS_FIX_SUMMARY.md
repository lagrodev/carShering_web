### 1. **Цвета в Календаре** 🎨
**Проблема**: Цвета не отображались правильно в зависимости от выручки.

**Исправление**:
- Исправлен алгоритм расчёта цвета
- Теперь используется нормализация от минимума до максимума
- Добавлена защита от пустых значений

**До**:
```javascript
const ratio = revenue / max  // Неправильно для разных диапазонов
```

**После**:
```javascript
const min = Math.min(...revenues)
const max = Math.max(...revenues)
const ratio = (revenue - min) / (max - min)  // Правильная нормализация
```

## 🚀 Как Проверить Исправления

### Шаг 1: Откройте Консоль
Нажмите `F12` и перейдите на вкладку **Console**

### Шаг 2: Загрузите Аналитику
1. Зайдите в панель администратора
2. Откройте вкладку "Аналитика"
3. Выберите период (например, "Месяц")

### Шаг 3: Проверьте Логи
Вы увидите в консоли:
```
🔄 [API Request] Loading daily revenue from: 2025-10-27 to: 2025-11-27
✅ [API Response] Received daily revenue data: Array(31)
📊 [Data Details] Number of days: 31
```

### Шаг 4: Проверьте Цвета
Календарь должен показывать разные оттенки зелёного:
- **Светло-зелёный** 🟢 - минимальная выручка
- **Тёмно-зелёный** 🟩 - максимальная выручка
- **Серый** ⬜ - нет данных

### Шаг 5: Проверьте Соответствие Данных
1. Кликните на любой день в календаре
2. В консоли увидите:
```
📊 [Day Summary]:
  - Contracts: 3
  - Total Cost: 5500
  - Revenue from table: 5500
  - Match: ✅  ← Должна быть галочка
```

Если увидите `❌` - это значит данные не совпадают и **проблема на бэкенде**.

## 🐛 Обнаружение Проблем на Бэкенде

### Признак 1: Несоответствие Сумм
```
⚠️ [Data Mismatch] Revenue in table: 5500 Total from contracts: 5000
⚠️ [Possible Issue] Backend may be returning inconsistent data
```

**Что это значит**: 
- API `/daily-revenue` вернул выручку 5500
- API `/contracts-by-day` вернул контракты на сумму 5000
- **Проблема на бэкенде** - разная логика подсчёта

### Признак 2: Есть Выручка, Но Нет Контрактов
```
❌ [Data Error] Revenue exists but no contracts found!
```

**Что это значит**:
- В таблице показана выручка
- Но контрактов на эту дату нет
- **Проблема на бэкенде** - данные не синхронизированы

### Признак 3: Неправильный Тип Данных
```
📊 [Day 0] Date: 2025-11-27, Revenue: "5000", Type: string  ← Должно быть number!
```

**Что это значит**:
- Бэкенд возвращает строку вместо числа
- **Нужно исправить бэкенд** - возвращать число

## 🔧 Что Делать, Если Проблемы на Бэкенде

### 1. Соберите Информацию
Скопируйте из консоли все логи с префиксами:
- `[API Request]`
- `[API Response]`
- `[Data Mismatch]`
- `[Data Error]`

### 2. Проверьте Network Tab
1. Откройте Dev Tools → Network
2. Найдите запросы:
   - `admin/stats/daily-revenue`
   - `admin/stats/contracts-by-day`
3. Сравните ответы

### 3. Проверьте Бэкенд
Проверьте, что оба API endpoint используют:
- Одинаковую фильтрацию контрактов (по статусу)
- Одинаковый расчёт выручки
- Одинаковую обработку дат (timezone)

# Руководство по Аналитической Панели Администратора

## 📊 Обзор

Новая аналитическая панель предоставляет администраторам мощные инструменты для анализа выручки и активности системы каршеринга. Реализация включает GitHub-style календарь, детальные таблицы, интерактивные графики и модальные окна с подробной информацией по каждому дню.

## 🚀 Новые API Методы

### 1. Общая статистика системы
```javascript
GET /api/admin/stats/overview
```
Возвращает сводную статистику:
- Общая выручка (за все время и за месяц)
- Количество контрактов (всего и за месяц)
- Количество пользователей (всего и активных)
- Количество автомобилей (всего и доступных)
- Общее время поездок (в минутах)

### 2. Выручка по дням за период
```javascript
GET /api/admin/stats/daily-revenue?from=YYYY-MM-DD&to=YYYY-MM-DD
```
Возвращает массив объектов:
```json
[
  {
    "date": "2025-11-27",
    "revenue": 45000.50
  }
]
```

### 3. Контракты за конкретный день
```javascript
GET /api/admin/stats/contracts-by-day?date=YYYY-MM-DD
```
Возвращает детальный список всех контрактов за день:
```json
[
  {
    "clientName": "Иван Иванов",
    "login": "ivan_ivanov",
    "carBrand": "Toyota",
    "carModel": "Camry",
    "CarClass": "Business",
    "carId": 42,
    "totalCost": 5500,
    "durationMinutes": 480,
    "dataStart": "2025-11-27T10:00:00",
    "dataEnd": "2025-11-27T18:00:00"
  }
]
```

## 🎨 Компоненты Фронтенда

### AdminAnalytics.vue
Главный компонент аналитической панели, включающий:

#### 1. **Статистические Карточки**
4 карточки с gradient-фоном:
- 💰 Общая выручка (зеленый градиент)
- 📄 Контракты (синий градиент)
- 👥 Пользователи (фиолетовый градиент)
- 🚗 Автомобили (оранжевый градиент)

Каждая карточка показывает общее значение и значение за текущий месяц.

#### 2. **Выбор Периода**
- **Быстрые диапазоны**: Неделя, Месяц, Квартал, Год
- **Пользовательский диапазон**: Выбор начальной и конечной даты
- Кнопка "Применить" для загрузки данных

#### 3. **GitHub-Style Календарь**
Визуализация выручки в виде календаря:
- Каждый день представлен квадратом
- Цвет зависит от выручки:
  - Серый: нет данных
  - Светло-зеленый: минимальная выручка
  - Темно-зеленый: максимальная выручка
- **Интерактивность**: 
  - Наведение показывает дату и сумму
  - Клик открывает детали дня
  - Выбранный день подсвечивается рамкой

#### 4. **Таблица Статистики**
Детальная таблица с колонками:
- Дата (DD.MM.YYYY)
- День недели
- Выручка (в рублях)
- Кнопка "Подробнее"

Строки:
- Hover эффект (серый фон)
- Выбранная строка подсвечивается (синий фон)

#### 5. **График Выручки**
Chart.js линейный график:
- Плавная линия (tension: 0.4)
- Заливка под графиком
- Адаптивный размер
- Форматирование в рублях
- Высота: 320px

#### 6. **Модальное Окно с Деталями Дня**
Открывается при клике на день в календаре или кнопку "Подробнее":

**Заголовок**: 
- Gradient фон (primary -> purple)
- Дата в формате DD.MM.YYYY
- Кнопка закрытия

**Сводка (4 метрики)**:
- Всего контрактов
- Общая выручка (зеленый)
- Общее время (синий)
- Средний чек (фиолетовый)

**Список Контрактов**:
Каждая карточка контракта содержит:
- Марка и модель автомобиля
- Класс автомобиля (badge)
- Информация о клиенте (имя и логин)
- Длительность аренды
- Время начала и окончания
- Стоимость (крупно, зеленым цветом)
- ID автомобиля

Стили:
- Border анимация при hover
- Тень при hover
- Grid layout для информации

## 🎯 Особенности Реализации

### 1. **Адаптивный Дизайн**
- Мобильные устройства: одна колонка
- Планшеты: 2 колонки для статистик
- Десктоп: 4 колонки для статистик

### 2. **Форматирование Данных**
```javascript
// Валюта
formatCurrency(45000) // "45 000 ₽"

// Дата
formatDate("2025-11-27") // "27.11.2025"

// Дата и время
formatDateTime("2025-11-27T10:00:00") // "27.11.2025, 10:00"

// Длительность
formatDuration(480) // "8 ч 0 мин"

// День недели
getDayOfWeek("2025-11-27") // "Среда"
```

### 3. **Цветовая Схема Календаря**
Алгоритм определения цвета:
```javascript
const max = Math.max(...dailyData.map(d => d.revenue))
const ratio = revenue / max

if (ratio < 0.2) return 'bg-green-200' // 0-20%
if (ratio < 0.4) return 'bg-green-400' // 20-40%
if (ratio < 0.6) return 'bg-green-600' // 40-60%
if (ratio < 0.8) return 'bg-green-700' // 60-80%
return 'bg-green-800' // 80-100%
```

### 4. **Состояния Загрузки**
- Кнопка "Применить" с индикатором загрузки
- Spinner в модальном окне при загрузке контрактов
- Disabled состояние кнопки во время загрузки

### 5. **Обработка Ошибок**
Все API вызовы обернуты в try-catch с уведомлениями:
```javascript
try {
  dailyData.value = await getDailyRevenue(dateFrom.value, dateTo.value)
} catch (error) {
  showNotification('Ошибка загрузки данных', 'error')
  console.error('Error loading daily revenue:', error)
}
```

## 🐛 Отладка

### Проблемы и Решения

**График не отображается**:
- Проверьте, что canvas элемент существует
- Используйте `nextTick()` перед рендерингом
- Проверьте данные в `dailyData`

**Календарь неправильно отображается**:
- Проверьте формат дат (YYYY-MM-DD)
- Убедитесь, что данные отсортированы
- Проверьте алгоритм группировки по неделям

**Модальное окно не закрывается**:
- Проверьте обработчик `@click.self`
- Убедитесь, что `showDayDetails` меняется
- Проверьте z-index

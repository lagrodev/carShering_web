## ✨ Ключевые изменения

### 1. Поддержка времени в датах (LocalDateTime)

**Было:**
```html
<input type="date" v-model="dateStart" />
<!-- Формат: 2025-11-25 -->
```

**Стало:**
```html
<input type="datetime-local" v-model="dateStart" />
<!-- Формат: 2025-11-25T14:30 -->
```

**Затронутые области:**
- Фильтры поиска автомобилей
- Создание контракта
- Обновление контракта

### 2. Расчёт стоимости по часам

**Было:** `Цена × Количество дней`

**Стало:** `Цена за час × Количество часов`

**Пример:**
- Период: 25.11.2025 14:00 → 25.11.2025 18:00
- Длительность: 4 часа (отображается как "4 часа (1 день)")
- Цена: 500 ₽/час
- **Итого: 2 000 ₽**

### 3. Статистика пользователя

**Новый эндпоинт:** `GET /overview/client`

**Отображаемые данные:**
- 🚗 Любимый автомобиль с изображением
- 📊 Общее количество поездок
- 📅 Поездки за текущий месяц
- 💰 Общая сумма затрат
- ⭐ Любимый бренд и класс авто
- ⏱️ Средняя длительность аренды
- 🕐 Обычное время начала поездок
- 💵 Средняя стоимость за час
- 📆 Дата последней поездки

## 🔧 Технические детали

### Формат дат
- **Входной формат:** `datetime-local` (HTML5)
- **Формат отправки:** ISO 8601 (`2025-11-25T14:30:00`)
- **Парсинг:** `new Date()` встроенный в JS
- **Отображение:** `toLocaleDateString()`, `toLocaleTimeString()`

### API эндпоинты
```
GET  /car/catalogue?date_start=2025-11-25T14:00&date_end=2025-11-27T14:00
POST /contracts (с dataStart и dataEnd в LocalDateTime)
GET  /overview/client (новый эндпоинт статистики)
```

### Валидация
- Минимальная дата: текущие дата и время
- Максимальная длительность: 7 дней (168 часов)
- Дата окончания >= даты начала
- Бронирование на 1 год вперёд

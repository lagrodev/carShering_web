# Страница статистики пользователя

## Обзор

Создана отдельная страница для отображения статистики и достижений пользователя. Статистика больше не отображается на странице профиля, а вынесена на отдельный маршрут `/statistics`.

## Изменения

### 1. Новая страница: `StatisticsView.vue`

**Маршрут:** `/statistics`

**Основные компоненты:**
- Hero-секция с градиентом и кнопкой "Назад"
- Компонент `UserStatsCard` с полной статистикой
- Блок быстрых действий с 3 карточками-ссылками:
  - Мои договоры → `/contracts`
  - Избранное → `/favorites`
  - Каталог → `/`

**Дизайн:**
- Градиентный фон страницы (from-gray-50 via-primary-50/20 to-purple-50/20)
- Hero-секция с градиентом от primary до purple
- Современные карточки с hover-эффектами
- Иконки для каждого раздела

## Навигация

Пользователь может попасть на страницу статистики:

1. **Из профиля** → Кнопка "Моя статистика" (градиентная, яркая)
2. **Из Header-меню** → Выпадающее меню → "Моя статистика"
3. **Прямая ссылка** → `/statistics`

## Статистические данные

Отображаемые метрики (из API `/stats/overview/client`):

### Основные показатели (3 цветные карточки):
- **Всего поездок** (синий) - totalRides
- **Этот месяц** (зелёный) - ridesThisMonth
- **Потрачено** (фиолетовый) - totalSpent

### Любимый автомобиль (если есть):
- Изображение автомобиля
- Бренд и модель
- Класс автомобиля

### Предпочтения:
- Любимый бренд (favoriteBrand)
- Предпочитаемый класс (topUsedCarClass)

### Активность:
- ✅ **Средняя длительность поездки** (averageTimeDrive) - в часах с иконкой ⏱️
- ✅ **Средняя стоимость за 1 час** (averageCost) - в рублях с иконкой 💰
- Обычное время начала (averageTimeToStartDrive)
- Последняя поездка (lastRideDate)

## Дизайн-особенности

### Цветовая схема:
- **Primary-Purple градиент** - основные акценты
- **Синий** (Blue 500-600) - общие поездки
- **Зелёный** (Green/Emerald) - поездки за месяц
- **Фиолетовый-розовый** (Purple-Pink) - расходы
- **Оранжевый-красный** - предпочтения
- **Голубой** (Cyan-Blue) - активность

### Анимации и эффекты:
- Hover-эффекты на карточках (scale, shadow)
- Градиентные декоративные blur-круги
- Иконки с цветами, соответствующими категории
- Плавные переходы (transition-all duration-300)
- Transform эффекты при наведении

### Адаптивность:
- Мобильная версия: 1 колонка
- Десктоп: 2-3 колонки (grid-cols-1 md:grid-cols-2/3)

## Состояния компонента

UserStatsCard поддерживает 4 состояния:

1. **Loading** - анимированный спиннер с текстом
2. **Error** - иконка ошибки с кнопкой "Повторить попытку"
3. **Empty** - когда нет данных (новый пользователь)
4. **Data** - полная статистика с анимациями

## API интеграция

**Endpoint:** `GET /stats/overview/client`

**Сервис:** `src/services/analyticsService.js`
```javascript
export const getUserStats = () => {
  return api.get('/stats/overview/client').then(response => response.data)
}
```

**Формат ответа:** См. UserStats schema в api-docs.json

## Преимущества новой структуры

✅ Чистая страница профиля - фокус на личных данных  
✅ Отдельная страница для статистики - лучше UX  
✅ Больше места для детальной визуализации  
✅ Быстрые действия на странице статистики  
✅ Легкий доступ из 2 мест (профиль + меню)  
✅ Современный дизайн с градиентами и анимациями
